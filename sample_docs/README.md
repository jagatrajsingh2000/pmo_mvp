# Sample PMO Timeline Inputs

Use these files to test the upload flow:

- `pmo_timeline_brd_sample.txt` covers BRD, scope, team availability, dates, milestones, and dependencies.
- `pmo_timeline_backlog_sample.csv` covers user stories, owners, estimates, dependencies, and deadlines.
- `pmo_timeline_resources_sample.csv` covers team structure and resource availability.
- `project_timeline_brief.txt` is a compact all-in-one brief.
- `project_requirements.xlsx` is an Excel-oriented sample.
